To create table, I have provided the SQL files in this folder.
After creating database, select your database (user_db), then go to SQL tab.
Once your're there, select the sql file (e.g. user_db.sql), open as notepad or programming editor like Notepad++.
Copy everything, then paste it to your SQL Query (phpMyAdmin), and click Go.
There you go you have created the table and its existing data I have.

If you want to backup/get the SQL statements of the table from phpMyAdmin you can export it.
Select table (e.g. useracount), click Export tab, and then click Export.
This will generate a SQL file and save in your computer and if you want to execute it, follow steps above.
*(This is also the same case if you select the database then export which will generate a single SQL file containing all of your tables and data in your database)
