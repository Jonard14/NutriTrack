# NutriTrack: A Personalized Tracking App
Repository for the NutriTrack App. A calorie tracking app which tracks the amount of calories and nutrition the user has consumed. The longer the app is used, the tracker will become more personalized and accurate to the user.

# CS134-1P-Thesis

This repository also serves as the Team project for our Software Engineering subject.

# Releases
The app can be downloaded from the [release](https://github.com/Jonard14/CS134-Thesis/tree/developoment-cs134-1p/Releases) page. The latest version will always be marked as latest while older versions will be marked with a version number.

# Installation
To install the app, download the zip file from the [release](https://github.com/Jonard14/CS134-Thesis/tree/developoment-cs134-1p/Releases) page, then unzip the APK from the downladed zip file. Simply install the APK into any mobile device you desire and the installation is complete!
